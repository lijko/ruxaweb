# Modèles officiels du SIP

Modèles du Service information et presse (SIP), Luxembourg, sous licence CC BY 3.0 LU, copiés tels quels. Ils remplacent la grille française du dépôt simplA11yMonit, obsolète (liens de calcul cassés : la synthèse restait à 0).

| Fichier | Usage dans RUXAWeb | Version reconnue |
|---|---|---|
| `template-grille-audit-simplifie.xlsx` | grille vierge de l'audit simple (3 pages, 53 critères) | modifiée le 2 juin 2026, révision 530 |
| `raweb1-1-lu-modele-grille-audit.xlsx` | grille vierge de l'audit complet (15 pages, 136 critères) | modifiée le 28 juillet 2026, révision 530 |
| `raweb1-1-lu-modele-rapport-audit.docx` | référence de structure du rapport d'audit Word (le rapport est généré par l'outil, sans charte) | |

Les deux grilles sont en anglais (onglets Sample, P01…, colonnes Status, Derogation, Problems detected). Les commentaires écrits par l'outil restent en français.
